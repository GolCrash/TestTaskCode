Запуск за пять шагов
1. Клонировать репозиторий

git clone <URL_РЕПОЗИТОРИЯ>
cd <ПАПКА_РЕПОЗИТОРИЯ>

2. Запустить MongoDB

Перейти в папку backend, где находится `docker-compose.yml`, и выполнить:

docker compose up -d

После запуска MongoDB будет доступна по адресу:

mongodb://localhost:27017

3. Запустить backend

В папке проекта `TestCode` выполнить:

dotnet restore
dotnet run

Swagger доступен через стандартный адрес, который выводится в консоли при запуске приложения.

4. Запустить frontend

npm run dev

Адрес frontend будет указан в консоли после запуска.

5. Загрузить тестовые данные

Отдельная ручная загрузка тестовых данных не требуется.

При старте backend автоматически вызывается инициализация базы данных. Если коллекция сотрудников пустая, в MongoDB добавляются тестовые:

* сотрудники;
* ставки;
* проекты;
* закрытый период;
* записи табеля.

Повторный запуск приложения не создаёт дубликаты тестовых данных, если сотрудники уже существуют в базе.
